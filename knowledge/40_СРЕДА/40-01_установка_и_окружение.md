# Установка и окружение

## Что нужно

| Что | Где берётся | Как находит mcukit |
|---|---|---|
| SEGGER J-Link Software | segger.com, пакет «J-Link Software and Documentation» | `MCUKIT_JLINK` → свежая `Program Files\SEGGER\JLink*` |
| arm-none-eabi-gcc | Arm GNU Toolchain или внутри STM32CubeIDE | `MCUKIT_GCC` → PATH → Arm GNU Toolchain → `C:\ST\STM32CubeIDE_*\...\gnu-tools-for-stm32*\tools\bin` |
| make | PATH или внутри STM32CubeIDE | `MCUKIT_MAKE` → PATH → `...\externaltools.make*\tools\bin\make.exe` |
| Python 3.11+ | python.org | — |

Рабочие папки заданий: `MCUKIT_WORK`, иначе `%LOCALAPPDATA%\Temp\mcukit`.
Там лежат файлы команд, журналы J-Link (`jlink.log`) и копии проектов —
первое место, куда смотреть при сбое.

Проверка:

```python
import mcukit as mk
mk.jlink_version(), mk.gcc_version(), mk.make_exe()
mk.probe()                 # зонд, VTref — к чипу не подключается
```

## Зонд с именем SAM-ICE

`ShowEmuList` показывает `ProductName: SAM-ICE`, железо J-Link V9.50,
лицензии `RDI,FlashBP,FlashDL,JFlash,GDB`. Официально SAM-ICE — вариант
J-Link для чипов Atmel/Microchip. Этот экземпляр подключился к GD32F470,
записал и прочитал флеш без ограничений. Другой экземпляр SAM-ICE может
вести себя иначе — проверять.

Замер `tests/test_hw.py`, SWD 4 МГц (`info` — 1 МГц):

## Установка набора

`tools/setup.ps1` (или двойной щелчок по `Install-skill.bat`): junction
скилла, `MCUKIT_HOME`, хук коммитов, локальный стоп-лист, проверка
программ. Прав администратора не требует.
